# Telegram-бот «Помощь в отказе от курения»

Учебный проект (КСР) по дисциплине «Цифровая культура».

## Возможности

- Информация о вреде курения
- Тест на никотиновую зависимость (адаптированный тест Фагерстрёма)
- Режим «Хочу бросить курить» с указанием даты, количества сигарет и цены пачки
- Отслеживание прогресса (дни, невыкуренные сигареты, сэкономленные деньги)
- **Геймификация** с достижениями до 3 месяцев:
  - 1 день — «Первый шаг»
  - 3 дня — «Трое суток»
  - 7 дней — «Неделя свободы»
  - 14 дней — «Две недели»
  - 30 дней — «Месяц без никотина»
  - 60 дней — «Два месяца»
  - 90 дней — «Три месяца свободы»
- SOS-кнопка при сильной тяге
- Простые настройки

## Как запустить

### 1. Создать бота
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot` и следуй инструкциям
3. Скопируй полученный токен

### 2. Установить зависимости
```bash
cd smoking_bot
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настроить токен
Создай файл `.env` в этой папке:
```
BOT_TOKEN=123456:ABC-DEF...твой_токен
```

### 4. Запустить
```bash
python bot.py
```

Бот заработает. Найди его в Telegram по имени, которое указал в BotFather, и нажми Start.

## Структура
- `bot.py` — основной код бота
- `requirements.txt` — зависимости
- `smoking_bot.db` — база данных (создаётся автоматически)
